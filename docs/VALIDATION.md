# 验证记录

- Node 数值测试：16 项（Lab D65 参考值、往返、75/25 红蓝块、透明/半透明、单色、区域、确定性、归一化、采样、恒等换色、alpha、灰度、色块）。
- JavaScript 语法：app / engine / worker。
- 单文件构建与多文件版共享引擎；CI 重新生成并核对 index.html。
- Chrome 浏览器实测：内置示例、PNG 本地导入、像素取色、框选区域、HEX 换色、收藏、PNG/JSON/GPL 色卡导出、JSON 导入恢复、明暗预览与工作图 PNG 导出。
- 浏览器上传 400×300 红蓝图（红 75%、蓝 25%），空间采样显示 74.6% / 25.4%，符合采样近似；在纯蓝区域框选后提取只得到 #0000FF / 100%。点击红区得到 #FF0000。
- 多文件版和打包单文件版均通过 HTTP 加载实际图像与计算；单文件 Blob Worker、明暗预览与 PNG 导出实测成功。
- 修改屋顶所属主色 #D57748 为 #8199B5，实际画面出现蓝色屋顶；相似色的花、木纹等也变化，符合最近色簇处理的限制。
- 预览截图：`docs/screenshots/workbench.png`。浏览器扩展自身有 metadata 错误日志，未见应用运行错误。
